## 4. 观察：自动更新绕过重启脚本

Electron 自动更新不经过我们的重启脚本 → 魔改不会自动补。当前只能：
- 用户手动跑一次 `ensure-session-hooks-patch.ps1` + 重启；或
- 下次走脚本重启时自动补（脚本幂等）。

**待考虑**：加一个启动后检查（例如 automation 定时巡检 bundle marker），发现丢失即提示。

## 5. 观察：loop 短闹钟被拒

0.930.1 下 `loop_control {action:"schedule", delay_seconds:30}` 被拒：
> Background work in this session wakes it automatically on completion; do not schedule alarms to poll it.
> While background work is live, alarms must be long fallbacks (>= 1200s).

对比两版 bundle 中 `1200` / `fallback alarm` / `loop_control` / `hang-protection` 的命中计数**完全一致**，
因此**不能归因于本次宿主改动**；更可能是「后台工作」判定口径或本会话确实存在活跃 deferred 占位所致。
待后续专项确认，不作为本次结论。
