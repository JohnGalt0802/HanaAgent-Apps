# 「小花下载器」插件 Icon 提示词

用于文生图（千问 / Z-Image / 其他）。参考图风格：日系动画插画，黑色齐脖短发 + 耳侧紫色挑染 + 黑色圆框眼镜 + 米白卫衣，木格窗暖光室内、墙面莫奈睡莲风油画、桌面笔记本电脑。

建议出图尺寸：1024×1024 或 1328×1328（方图）。方块在画面里占 1/4 以上，文字才不容易糊。

## 如果出问题，对症加词

- 字写错 / 写成英文 / 乱码：在做完提示词后追加「方块上的五个汉字必须准确清晰：小、花、下、载、器，不可出现错字、乱码或英文字符。」
- 方块被画成手机或平板：追加「方块的表面是纯色哑光的，没有屏幕、没有 UI 界面、没有手机边框，只是一个浅灰白色的软胶方块。」
- 脸被方块挡住：把「脸完整地出现在方块左上方的中景位置」改成「脸的完整轮廓必须露在方块旁边，方块与脸之间留出空隙，方块不得压住脸部一寸。」
- 绿色箭头跑到画外或变形：把箭头那句改成「方块正面底部居中有一个粗的绿色实心向下箭头，形状规整对称，箭头长度约占方块高度的四分之一。」
- 画风偏 3D / 塑料：追加「二维平面插画，不要三维渲染，不要塑料反光，线条是干净的深色描边，上色是平涂加柔和渐变。」
